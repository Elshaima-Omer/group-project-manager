================================================================================
SCHOLARSYNC — CLASSROOM SETUP (follow in order)
================================================================================

You only need to do TWO things yourself:
  (A) Run SQL in Supabase  — one time
  (B) Run the website      — npm run dev

All app code is already updated in your project folder.

================================================================================
PART A — DATABASE (Supabase website, ~5 minutes)
================================================================================

STEP 1 — Open Supabase
  1. Go to https://supabase.com and log in
  2. Open your ScholarSync project (the one with URL pgppxwoqulyousepqyno)

STEP 2 — Run the SQL script
  1. In the left menu, click "SQL Editor"
  2. Click "New query"
  3. On your computer, open this file in Notepad:
       supabase/classrooms-setup.sql
  4. Select ALL text (Ctrl+A), Copy (Ctrl+C)
  5. Paste into the Supabase SQL box
  6. Click "Run" (or press Ctrl+Enter)
  7. You should see "Success" — if you see an error, copy it and ask for help

STEP 3 — Check it worked
  1. In the left menu, click "Table Editor"
  2. You should see a new table called "classrooms"
  3. Click "projects" — you should see a new column "classroom_id"

================================================================================
PART B — RUN THE WEBSITE ON YOUR COMPUTER
================================================================================

STEP 4 — Open terminal in your project folder
  1. In Cursor, open the terminal (Terminal → New Terminal)
  2. Make sure you are in the scholarsyncweb-main folder

STEP 5 — Install and start (if not already running)
  Type these commands one at a time, press Enter after each:

    npm install
    npm run dev

  3. Open the link it shows (usually http://localhost:5173)

================================================================================
PART C — HOW TO USE IT (test with two accounts)
================================================================================

AS PROFESSOR:
  1. Log in as professor
  2. Click "Classrooms" in the left menu
  3. Click "New classroom"
  4. Enter name (e.g. CS-498 Capstone) → Create
  5. COPY the 6-letter code (e.g. K7M2XP) — send this to students

AS STUDENT:
  1. Log in as student
  2. Projects → Create Project
  3. At the top: paste classroom code → click "Verify code"
  4. Fill in project details → Create Project

AS PROFESSOR AGAIN:
  1. Go to Dashboard
  2. You should see ONLY projects that used your classroom code
  3. Click "Report" on a project to view details

================================================================================
TROUBLESHOOTING
================================================================================

"Could not load classrooms" or "relation classrooms does not exist"
  → You did not run the SQL in Part A. Do Step 2 again.

"Failed to create project" mentioning classroom_id
  → Run the SQL again. The projects table needs the classroom_id column.

Professor dashboard is empty
  → Create a classroom first, then have a student create a project with that code.

Student "No classroom found"
  → Code must match exactly (letters/numbers, no spaces). Professor must share the code from Classrooms page.
